# Cybersecurity Lab Resources

مرجع منظم للمختبر. الروابط الخارجية يجب أن تكون لمصادر رسمية أو مفتوحة المصدر موثوقة، ويُفضّل تثبيت التطبيقات من مصدرها الرسمي أو F-Droid/GitHub releases عند توفر ذلك.

## Learning / CTF
- OWASP Web Security Testing Guide
- OWASP Juice Shop
- PortSwigger Web Security Academy
- picoCTF
- OverTheWire

## Android / APK
- F-Droid: مستودع تطبيقات Android مفتوحة المصدر.
- GitHub Releases: استخدم صفحة Releases الرسمية للمشروع بدل APKs المعاد رفعها من مواقع مجهولة.

> لا يتم تخزين ملفات APK ثنائية داخل المستودع. هذا الملف يحتفظ بفهرس وروابط المصادر فقط، لتقليل مخاطر الملفات المعدلة أو الخبيثة.

## Lab principles
- الأهداف المحلية أو المصرح بها فقط.
- Safety Guard إلزامي قبل أي active scan.
- سجّل النطاق والوقت والنتائج لكل اختبار.
- لا تحفظ كلمات مرور أو مفاتيح API داخل التقارير أو Git.
