# Free Cybersecurity Community Forum Blueprint

## Goal
منتدى مجاني مرتبط بالمختبر للتعلم، CTF، مشاركة write-ups، الأسئلة، والتوثيق الدفاعي.

## Sections
1. Announcements
2. Getting Started
3. Termux Lab
4. Web Security
5. API Security
6. Android Security
7. CTF Write-ups
8. Defensive Security
9. Tools & Automation
10. Responsible Disclosure

## Moderation and safety
- ممنوع نشر بيانات اعتماد، مفاتيح API، أو بيانات شخصية.
- ممنوع نشر أهداف حقيقية أو طلبات لاستهداف أنظمة بدون تصريح.
- استخدم أمثلة محلية وCTF عند مشاركة خطوات الاستغلال.
- أضف قالبًا لكل write-up: Scope → Lab/Target → Finding → Evidence → Fix.

## Free hosting path
يمكن استضافة واجهة المنتدى كتطبيق ويب مجاني/تجريبي عبر مزود استضافة يدعم النشر من GitHub. لا تُضمّن أسرارًا في المستودع، واجعل التسجيل والـmoderation منفصلين عن أدوات الفحص.
